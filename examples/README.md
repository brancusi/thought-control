# Sample vault

`sample-vault/` was generated by `scripts/seed-sample.sh`. It holds:

- `log/sample-laptop/*.jsonl`: the event log, which is the **only** source of truth. One JSON event per line.
- `export/`: the read-only Markdown export (`thc export`), readable in Obsidian.

To explore it:

```bash
THC_VAULT=examples/sample-vault thc today
THC_VAULT=examples/sample-vault thc agenda
THC_VAULT=examples/sample-vault thc log
```

Dates are relative to the day it was generated (2026-10-03).
